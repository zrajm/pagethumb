* DONE Don't close popup if unfocused tab reloads
  CLOSED: [2026-10-03 Sat 02:51]
  Closing when user switches tab (`onActivated`) is intentional and fine. The
  problem is that in the `tabs.onUpdated` listener fires for every tab,
  including background ones. If a background tab navigates or reloads while the
  popup is open (for example a page redirecting itself or a restored tab
  finishing loading) the popup closes even though the user didn't change
  anything in the tab they're looking at.
* DONE Only wake background script on URL change
  CLOSED: [2026-10-03 Sat 02:40]
  `tabs.onUpdated` wakes the event page far more often than needed.

  It fires for title, favicon and loading-status changes, and you ignore all of
  them via `if (!url) return`. Each one wakes a suspended page and reruns
  `setupBookmarkFolders()`. Use the Firefox event filter, which avoids this:

    browser.tabs.onUpdated.addListener((tabId, { url }) => {
      ...
    }, { properties: ['url'] })
* DONE Update button when single-page apps change the URL
  CLOSED: [2026-08-27 Thu 14:38]
  Youtube did not update the 👍 / 👎 in the extension button when navigating
  between videos. This turned out to be because it's a single-page app (SPA)
  and those use the History API's `pushState()` and `replaceState()` instead of
  loading pages.

  Pagethumb now ignores what *type* of event that caused the URL update and
  instead react to all URL changes. This also makes the plugin slightly faster
  at reacting to new URLs, as we no longer wait for a page to finish loading
  before updated the extension button's state.
